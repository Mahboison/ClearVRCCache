# ClearVRCCache
A simple powershell script for clearing those pesky cache files that pile up and bog down your VRChat

## Usage
Just download the repository and put it anywhere on your computer (except inside the VRChat cache folders, you silly goose), and run ClearVRCCache.bat to wipe VRChat's cache clean.

Bear in mind that you will need to re-download avatars and worlds you've previously seen/visited when you hop back onto the game, but this can fix world loading loops and friends' avatars that wouldn't load previously. It will also free up space on your hard drive, which can lead to marginal performance boosts.

## Disclaimer

Running this while the game is running will probably lead to bad things happening, like the game crashing, so please refrain from doing that. I bear no responsibility for the consequences if you do.

This script probably won't work if you've symlinked VRChat's cache to be somewhere else. If you don't know what that means, don't worry about it and just use the script as-is.
